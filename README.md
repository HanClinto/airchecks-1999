# airchecks-1999

Annotated catalog of aircheck samples from the archive.org "airchecks"
collection, starting with 1999, extensible to any year/item.

An aircheck is a recording of a radio station airing — rare bootleg
provenance artifacts useful for collectors, archivists, and fans of
personalities, contests, commercials, events, and exclusive music.

## Status (as of 2026-11-25)

- Scope: 1999 audio samples from the `airchecks` collection (244 exact + broad
  text:1999 set). Goal: structured annotations for collectors and archivists.
- Repo initialized; initial index in `data/airchecks-1999-candidates.json`.
- See `docs/PROJECT.md` for project framing, schema, methodology, gates.

## Risks at a glance

- 1999-exact vs broad 1999 is a real scope ambiguity (see
  `docs/PROJECT.md`).
- Will Smith "Wild Wild West" is not currently present in the 1999 audio set
  — needs a second targeted search.
- Archive.org comments require a human reviewer; the repo is text-first so
  approved annotations can be crossposted manually.
